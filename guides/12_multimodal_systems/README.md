# Area 12 — Multimodal systems (terms + glossary shortcut)

<!-- guide-kind: terms-only -->

ဤဖိုင်သည် area 12 ၏ term ၁၅ ခုကို အတိုချုံး ရှင်းပြထားသည်။ term တိုင်းကို — term ဆိုတာ ဘာလဲ၊ ဥပမာ တစ်ခု၊
အတိုင်းအတာ သို့မဟုတ် အသုံးဝင်ပုံ ဆိုတဲ့ ၃ ကြောင်းဖြင့် ရေးထားသည်။ term ၁၅ ခုကို အဆင့် ၄ ခုအဖြစ် စီထားသည်။

## ၁။ modality နှင့် model အမျိုးအစားများ

### Modality

Modality ဆိုတာ ကိုယ်ပိုင် တည်ဆောက်ပုံနှင့် ရယူသည့် လုပ်ငန်းစဉ် ရှိတဲ့ အချက်အလက် ပုံစံ တစ်မျိုးကို ဆိုလိုပါတယ် — text၊ image၊ audio၊ video၊ depth၊ sensor တိုင်းတာချက် စသဖြင့်။
ဥပမာ ဓာတ်ပုံတစ်ပုံနဲ့ အဲဒီ အကြောင်း ရေးထားတဲ့ စာသား ဆိုရင် modality ၂ မျိုး ဖြစ်ပါတယ် — တစ်မျိုးချင်း ဖတ်ပုံ မတူပါဘူး။
Modality မတူရင် sampling rate၊ noise နဲ့ spatial သို့မဟုတ် temporal တည်ဆောက်ပုံ မတူသဖြင့် preprocessing ယူဆချက် တစ်ခုတည်းက အားလုံးအတွက် မသင့်ပါဘူး။

### Multimodal Model

Multimodal Model ဆိုတာ modality တစ်မျိုးထက် ပိုနဲ့ တွဲဖက် လုပ်နိုင်တဲ့ model ကို ဆိုလိုပါတယ် — ဆက်စပ်ခြင်း၊ ဘာသာပြန်ခြင်း သို့မဟုတ် ဖန်တီးခြင်း ပါဝင်နိုင်ပါတယ်။
ဥပမာ ရုပ်ပုံ model တစ်ခုနဲ့ စာသား model တစ်ခု သီးသန့် ထားပြီး ဆက်ခေါ်ရင် စနစ်အဆင့်မှာ multimodal ဖြစ်ပေမယ့် တစ်ခုတည်း train လုပ်ထားတဲ့ multimodal model မဟုတ်ပါဘူး။
အင်ဂျင်နီယာ အရ အရေးပါတာက model တစ်ခုတည်း လား၊ ဆက်ခေါ်ထားတာ လား ဆိုတာ ခွဲသိထားခြင်း ဖြစ်ပါတယ်။

### Vision-Language Model (VLM)

VLM ဆိုတာ ရုပ်ပုံနဲ့ စာသား ဆက်စပ်မှုကို သင်ယူပြီး နှစ်မျိုးလုံးကို တွဲဖက် ဆောင်ရွက်တဲ့ model ကို ဆိုလိုပါတယ် — ရှာဖွေခြင်း၊ ဖော်ပြခြင်း၊ မေးခွန်း ဖြေခြင်း စသဖြင့်။
ဥပမာ ရုပ်ပုံ ၁ ပုံနဲ့ စာသား ၁ ကြောင်း တွဲသွင်းပြီး "တူညီလား" ဆိုတဲ့ မေးခွန်း ဖြေစေရင် အဲဒါ VLM အလုပ်တစ်မျိုး ဖြစ်ပါတယ်။
ရုပ်ပုံ လက်ခံတာနဲ့ ရုပ်ပုံကို အမှန်တကယ် အသုံးချတာ မတူပါဘူး — VLM ဖြစ်ရင် ရုပ်ပုံ ဖန်တီးနိုင်တယ်လို့လည်း မဆိုနိုင်ပါဘူး။

### Vision Transformer (ViT)

ViT ဆိုတာ ရုပ်ပုံကို patch များအဖြစ် ခွဲပြီး အဲဒီ patch များကို အစဉ်လိုက် token များအဖြစ် transformer ထဲ ထည့်တဲ့ architecture ကို ဆိုလိုပါတယ်။
ဥပမာ ရုပ်ပုံ 224×224 ကို patch 16×16 နဲ့ ခွဲရင် patch ၁၉၆ ခု ရပြီး token ၁၉၆ ခု အဖြစ် ထည့်ပါတယ်။
ViT ဆိုတာ architecture အုပ်စုတစ်ခု ဖြစ်ပြီး ရုပ်ပုံ လက်ခံတဲ့ transformer တိုင်း ViT မဟုတ်သလို patch များလည်း အရာဝတ္တု မဟုတ်ပါဘူး။

## ၂။ input ကို token အဖြစ် ပြောင်းခြင်း

### Patch Embedding

Patch Embedding ဆိုတာ ရုပ်ပုံ patch တစ်ခုကို အကျယ်တူ vector တစ်ခုအဖြစ် ပြောင်းတဲ့ သင်ယူထားသည့် ပြောင်းလဲမှုကို ဆိုလိုပါတယ်။
ဥပမာ patch 16×16 pixel နဲ့ channel ၃ ခု ဆိုရင် တန်ဖိုး 768 ခု ရှိပြီး projection တစ်ခုနဲ့ 768-dim vector ၁ ခု ဖြစ်သွားပါတယ်။
Patch embedding ဆိုတာ patch တစ်ခုရဲ့ vector ဖြစ်ပြီး အရာဝတ္တု ရှာသည့် စနစ် မဟုတ်ပါဘူး — patch အနားသတ်က အရာဝတ္တုနဲ့ တိုက်ဆိုင်ချင်မှ တိုက်ဆိုင်ပါမည်။

### Image Token

Image Token ဆိုတာ ရုပ်ပုံရဲ့ အစိတ်အပိုင်း (patch၊ region သို့မဟုတ် codebook entry) ကို ကိုယ်စားပြုတဲ့ model-specific ယူနစ်ကို ဆိုလိုပါတယ်။
ဥပမာ patch တစ်ခုရဲ့ vector ကို image token ၁ ခု အနေနဲ့ ရေတွက်ရင် ရုပ်ပုံတစ်ပုံဟာ token ၂၅၆ ခု ဖြစ်နိုင်ပါတယ်။
Image token ၁ ခုဟာ pixel ၁ ခု၊ အရာဝတ္တု ၁ ခု သို့မဟုတ် ဧရိယာ အတိအကျ ၁ ခု မဟုတ်ပါဘူး — tokenizer အလိုက် ကွာပါတယ်။

### Audio Token

Audio Token ဆိုတာ အသံ အပိုင်းအစ တစ်ခုကို ကိုယ်စားပြုတဲ့ codec သို့မဟုတ် tokenizer ထုတ်ပေးသည့် ယူနစ်ကို ဆိုလိုပါတယ် — codebook များစွာ ဖြစ်နိုင်ပါတယ်။
ဥပမာ တစ်စက္ကန့်လျှင် token ၅၀ ထုတ်တဲ့ codec နဲ့ တစ်မိနစ် အသံကို ရေတွက်ရင် token ၃,၀၀၀ ရပါတယ်။
Audio token ဟာ အချိန်တာ အတိအကျ၊ သံ သို့မဟုတ် စကားလုံး တစ်လုံး မဟုတ်ပါဘူး — tokenizer နဲ့ codebook အလိုက် ကွာပါတယ်။

### Automatic Speech Recognition (ASR)

Automatic Speech Recognition ဆိုတာ အသံကို စာသား (transcription) အဖြစ် ပြောင်းတဲ့ လုပ်ငန်းစဉ်ကို ဆိုလိုပါတယ် — အချိန်အမှတ်အသားနဲ့ ယုံကြည်မှုအဆင့် ပါနိုင်ပါတယ်။
ဥပမာ ၁၀ မိနစ် အသံဖိုင် ဖြတ်ရင် စကားလုံး ၁,၅၀၀ ခန့် စာသား ရနိုင်ပါတယ်။
ASR က ဘာပြောခဲ့လဲ ပေးတာဖြစ်ပြီး ဘယ်သူ ပြောခဲ့လဲ ဆိုတာ သီးသန့် လုပ်ရပါတယ် — diarization သို့မဟုတ် speaker recognition။

## ၃။ modality များ ဆက်စပ်ခြင်းနှင့် ပေါင်းခြင်း

### Modality Alignment

Modality Alignment ဆိုတာ modality မတူတဲ့ representation များကြား ဆက်စပ်မှုကို တည်ဆောက်တာကို ဆိုလိုပါတယ် — အဓိပ္ပာယ် တူသည့် အရာများ တွဲမြင်နိုင်စေရန်။
ဥပမာ ရုပ်ပုံ ၁ ပုံနဲ့ အဲဒီ ရုပ်ပုံရဲ့ caption ကို space တစ်ခုတည်းမှာ နီးအောင် train လုပ်ရင် alignment ဖြစ်ပါတယ်။
Alignment က representation များကို နှိုင်းယှဉ်လို့ ရစေတာဖြစ်ပြီး တူညီသွားရန် မလိုပါဘူး — modality-specific အချက်အလက် ရှိရပါမည်။

### Shared Embedding Space

Shared Embedding Space ဆိုတာ modality အမျိုးမျိုးရဲ့ representation များကို similarity function တစ်ခုတည်းနဲ့ နှိုင်းယှဉ်နိုင်သည့် vector space ကို ဆိုလိုပါတယ်။
ဥပမာ ရုပ်ပုံ vector နဲ့ စာသား vector ကို cosine similarity နဲ့ နှိုင်းလို့ ရအောင် cross-modal training လုပ်ထားရပါတယ်။
Dimension တူညီတာဟာ အဓိပ္ပာယ် space တူတာ မဟုတ်ပါဘူး — training objective နဲ့ data က တည်ဆောက်ပေးရပါတယ်။

### Cross-Attention

Cross-Attention ဆိုတာ query က sequence တစ်ခုကနေ၊ key နဲ့ value က အခြား sequence တစ်ခုကနေ လာတဲ့ attention ကို ဆိုလိုပါတယ်။
ဥပမာ decoder က စာသား query နဲ့ vision encoder က ရုပ်ပုံ key/value ကို တွဲရင် ရုပ်ပုံထဲ ကြည့်ရမည့် နေရာကို ရွေးတဲ့ cross-attention ဖြစ်ပါတယ်။
Cross-attention ဟာ multimodality အတွက်သာ မဟုတ်ပါဘူး — စာသား ၂ ခုကြားမှာလည်း အသုံးပြုနိုင်ပါတယ်။

### Multimodal Fusion

Multimodal Fusion ဆိုတာ modality တစ်မျိုးထက် ပိုရဲ့ အထောက်အထားကို ပေါင်းပြီး တစ်ခုတည်း representation သို့မဟုတ် ရလဒ် ထုတ်တာကို ဆိုလိုပါတယ်။
ဥပမာ ရုပ်ပုံ feature နဲ့ စာသား feature ကို vector တစ်ခုတည်း ပေါင်းပြီး class ခွဲရင် အဲဒါ fusion ဖြစ်ပါတယ်။
Fusion က ပေါင်းတဲ့ လုပ်ဆောင်ချက် ဖြစ်ပြီး alignment က ဆက်စပ်မှု တည်ဆောက်တာ ဖြစ်ပါတယ် — modality ၂ ခုကို request တစ်ခုထဲ ထည့်ရုံနဲ့ နှစ်မျိုးလုံး ဖြစ်လာတာ မဟုတ်ပါဘူး။

### Early Fusion

Early Fusion ဆိုတာ modality များကို အလွှာ နည်းတဲ့ အဆင့် (raw သို့မဟုတ် low-level representation) မှာ ပေါင်းတာကို ဆိုလိုပါတယ်။
ဥပမာ ရုပ်ပုံ patch token နဲ့ စာသား token ကို token sequence တစ်ခုတည်းအဖြစ် ရောပြီး transformer ထဲ တစ်ခါတည်း ထည့်ရင် early fusion ဖြစ်ပါတယ်။
Early fusion ဆိုတာ ပေါင်းတဲ့ နေရာကို ပြောတာဖြစ်ပြီး ဆက်စပ်မှု ကောင်းကောင်း သင်ယူသွားတယ်လို့ အာမမခံပါဘူး။

### Late Fusion

Late Fusion ဆိုတာ modality တစ်ခုစီကို သီးသန့် encoder နဲ့ ဆောင်ရွက်ပြီး ရလဒ် သို့မဟုတ် score များကို အဆုံးအဆင့်နားမှာ ပေါင်းတာကို ဆိုလိုပါတယ်။
ဥပမာ ရုပ်ပုံ model တစ်ခုနဲ့ စာသား model တစ်ခု ရလဒ် ထုတ်ပြီး score ၂ ခုကို အလေးချိန်နဲ့ ပေါင်းရင် late fusion ဖြစ်ပါတယ်။
Late fusion ဆိုတာ ပေါင်းတဲ့ နေရာကို ပြောတာဖြစ်ပြီး ရိုးရိုး ပျမ်းမျှချတာ မဟုတ်သလို modality ၂ ခု အညီအမျှ ပါဝင်တယ်လို့လည်း မဆိုနိုင်ပါဘူး။

## ၄။ ရုပ်ပုံထဲ နေရာ ညွှန်ခြင်း

### Visual Grounding

Visual Grounding ဆိုတာ စာသား ဖော်ပြချက်ကို ရုပ်ပုံ သို့မဟုတ် video ထဲက နေရာ (region၊ object၊ mask သို့မဟုတ် လိုက်လံသည့် အရာ) နဲ့ ချိတ်ဆက်တာကို ဆိုလိုပါတယ်။
ဥပမာ "ဘယ်ဘက်က ခွေး" ဆိုတဲ့ စာသားကို ရုပ်ပုံထဲက bounding box တစ်ခုနဲ့ ချိတ်ပြရင် အဲဒါ grounding ဖြစ်ပါတယ်။
Grounding က ဘယ်နေရာလဲ ဖြေတာဖြစ်ပြီး caption ရေးတာက နေရာ မညွှန်ဘဲ ဖော်ပြနိုင်ပါတယ်။
